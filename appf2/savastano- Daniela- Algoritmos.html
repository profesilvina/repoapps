🕵️ Detectives de algoritmos

Tecnología · 3.º grado de primaria

Tu misión

Un algoritmo es una serie de instrucciones claras y ordenadas para realizar una tarea. Vas a investigar algoritmos con pasos desordenados, incompletos o poco claros.

Importante: la aplicación no te dará la solución. Si algo no funciona, podrás pedir preguntas orientadoras y pistas.

Misión 1 de 50%
Misión 1 · Secuencia

El misterio del té imposible

Los pasos están desordenados. Ordenalos para que una persona pueda preparar y beber el té. Tocá Subir o Bajar en cada tarjeta hasta colocarla en el lugar que corresponda.

    Una instrucción sospechosa

    Leé este algoritmo para guardar un trabajo escolar:

    1. Abrir la carpeta.
    2. Guardar el trabajo ahí.
    3. Cerrar todo.

    Una decisión según el clima

    Una condición permite que el algoritmo tome caminos diferentes. Observá:

    Pregunta¿Está lloviendo?
    Si la respuesta es síLlevar paraguas.
    Si la respuesta es noContinuar sin paraguas.

    El robot que riega plantas

    Hay 6 plantas en una fila. El robot debe regar cada planta una sola vez. Elegí una instrucción que sea clara y evite escribir seis veces la misma acción.

    ¿Qué instrucción usarías?
    Misión 5 · Depuración

    El correo que nunca salió

    Este algoritmo debería permitir enviar un correo, pero falta un paso. Marcá el lugar donde debería agregarse.

    1. Abrir el correo electrónico.
    2. Escribir la dirección de la persona destinataria.
    3. Escribir el asunto.
    4. Redactar el mensaje.
    5. Cerrar la aplicación.
